# РабКаб

Публичная раздача установщиков и бинарных обновлений приложения. Исходный код хранится отдельно.

## Установка

1. Откройте [последний релиз](https://github.com/lazydq33/RabKab-Distribution/releases/latest).
2. Скачайте `RabKabSetup-1.9.8.exe` и запустите установщик.
3. Для перехода с прежней версии установите РабКаб 1.9.8 один раз. После этого новые версии устанавливаются через «Проверить обновления» внутри приложения.

## Обновления

Встроенный механизм проверяет `update.json`, загружает пакет версии и сверяет SHA-256 перед заменой приложения.
