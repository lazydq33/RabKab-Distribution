# Индустрия — канал раздачи

Публичный каталог установщиков и бинарных обновлений приложения «Индустрия». Исходный код хранится отдельно.

## Текущая версия канала

**1.9.16** — стабильная правка ячеек, вкладка «Настройки», автоматические резервные копии. Манифест обновления: [`update.json`](update.json).

## Установка

1. Откройте [последний релиз](../../releases/latest).
2. Для первой установки скачайте установщик из релиза `v1.9.8` (`RabKabSetup-1.9.8.exe`) и запустите его.
3. После первой установки обновления приходят через «Проверить обновления» внутри приложения — установщик больше не нужен.

## Обновления

Встроенный механизм читает `update.json`, скачивает пакет версии `IndustriaPackage-<версия>.bin` и сверяет SHA-256 перед заменой приложения. Принимаются только адреса вида `https://github.com/<owner>/<repo>/releases/download/...`.

Перед установкой обновления каталог данных копируется, а после перезапуска приложение проверяет данные и при необходимости возвращает копию.

## Состав релиза 1.9.16

- `IndustriaPackage-1.9.16.bin` — пакет обновления (исполняемый файл приложения).
- `Industria-source-1.9.16.zip` — исходный код версии.
- `Industria-Guide-1.9.16.md` — краткая инструкция.

Установщики `Setup`/`Update` для 1.9.16 не публиковались: пакет собирается скриптом `build.sh` в окружении с NSIS. Обновление существующей установки выполняется внутри приложения.
