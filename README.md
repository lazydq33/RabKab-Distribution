# Индустрия — канал раздачи

Публичный каталог установщиков и бинарных обновлений приложения «Индустрия». Исходный код хранится отдельно.

## Текущая версия канала

**1.9.15** — новый интерфейс. Манифест обновления: [`update.json`](update.json).

## Установка

1. Откройте [последний релиз](../../releases/latest).
2. Для первой установки скачайте установщик из релиза `v1.9.8` (`RabKabSetup-1.9.8.exe`) и запустите его.
3. После первой установки обновления приходят через «Проверить обновления» внутри приложения — установщик больше не нужен.

## Обновления

Встроенный механизм читает `update.json`, скачивает пакет версии `IndustriaPackage-<версия>.bin` и сверяет SHA-256 перед заменой приложения. Приложение принимает только адреса вида `https://github.com/<owner>/<repo>/releases/download/...`.

## Состав релиза 1.9.15

- `IndustriaPackage-1.9.15.bin` — пакет обновления (исполняемый файл приложения).
- `Industria-source-1.9.15.zip` — исходный код версии.
- `Industria-Guide-1.9.15.md` — краткая инструкция.

Установщики `Setup`/`Update` для 1.9.15 не публиковались: пакет собирается скриптом `build.sh` в окружении с NSIS. Обновление существующей установки выполняется внутри приложения.
